# 视觉处理学习课程：深度学习视觉 · 多模态 · 三维方向

> Computer Vision Course — DL Vision · Multimodal · 3D Track
>
> 一套 **8 阶段 · 34 课 + 毕业项目** 的深度学习视觉路线：环境装备 → 图像/张量 → CNN 分类 → 目标检测/分割 → 三维视觉几何 → 深度估计与重建（NeRF/3DGS）→ 视觉 SLAM → 视觉多模态（CLIP/VLM/扩散）。全程走 WSL2 + CPU 本机 / AutoDL 云端，沿三维方向收口，毕业项目做"三维重建 + 语义理解"端到端 demo。

- 学习方案：《[视觉处理学习方案.md](视觉处理学习方案.md)》——8 阶段拆解、逐课内容与代码、论文阅读路线、里程碑验收

## 课程地图（8 阶段 34 课 + 毕业项目）

- **阶段0 环境装备**（3 课）——WSL2 / AutoDL 环境、镜像、张量入门
- **阶段1 图像与张量的语言**（3 课）——图像读写、颜色空间、张量运算、autograd、DataLoader
- **阶段2 神经网络与图像分类**（5 课）——MLP、反向传播、CNN、经典网络、迁移学习
- **阶段3 目标检测与实例分割**（5 课）——IoU/mAP、Faster R-CNN、YOLO、U-Net、Mask R-CNN
- **阶段4 三维视觉的几何根基**（5 课）——相机模型、刚体变换、对极几何、三角化/PnP、立体视觉
- **阶段5 深度估计与三维重建**（5 课）——单目深度、立体匹配、SfM(COLMAP)、NeRF、3DGS
- **阶段6 视觉 SLAM**（4 课）——ORB 特征、视觉里程计、ORB-SLAM、回环检测
- **阶段7 视觉多模态**（4 课）——CLIP 对比学习、VLM 推理、扩散模型、文本/图像到 3D
- **毕业项目** —— 三维重建 + 语义理解融合的端到端 demo（阶段 5–7 穿插，最终章给出）

## 阅读顺序

1. 先读"0. 方案总览"与"1. 阶段总览"定全貌
2. 按阶段 0 → 7 顺序推进，每课跑文中代码并过里程碑（每 2 阶段一次验收）
3. 论文阅读路线穿插在各阶段；学完阶段 5 起可并行做毕业项目
